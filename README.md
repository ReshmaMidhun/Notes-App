# 📝 Note App

A lightweight browser-based note-taking application built with **HTML, CSS, and JavaScript**.  
This app allows users to create, edit, and delete notes, with data stored locally in the browser using **LocalStorage**.

---

## 🚀 Features
- Add new notes with a title and body.
- Edit existing notes seamlessly.
- Delete notes when no longer needed.
- Persistent storage using LocalStorage (notes remain after page reload).
- Clean and responsive UI built with CSS.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3
- **Logic:** JavaScript (ES6)
- **Storage:** LocalStorage
